# Worklog Canvas

タスク一覧と、1日の作業時間を記録する作業バーを管理し、タスク別の作業時間と進捗を可視化するWindows用デスクトップアプリ。仕様は [SPEC.md](SPEC.md) を参照。

> 開発中（M5: 共有フォルダ対応・バックアップ・異常系・個別閲覧とチーム一覧まで実装済み）。exe化・予定表ファイルの取り込み手順は後続のマイルストーンで追記する。

## 開発環境

- Python 3.12

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 起動

```bat
python -m worklog_canvas
```

初回起動時にデータフォルダを選ぶ（選んだフォルダは `%APPDATA%\WorklogCanvas\settings.json` に保存）。
利用者はWindowsのユーザー名で識別する。

確認用に、データフォルダとユーザー名を指定して起動できる。サンプルデータは書き換わるので、コピーして使う。

```bat
xcopy /E /I sample_data %TEMP%\wc_sample
python -m worklog_canvas --data %TEMP%\wc_sample --user fukui
```

### タイムラインの操作

| 操作 | 動作 |
|---|---|
| 空き時間を縦にドラッグ | 作業バーを作成し、入力ポップアップを表示 |
| ポップアップで文字を入力してEnter | 単発作業として記録 |
| ポップアップで↑↓で候補を選んでEnter、または候補をクリック | タスクとして記録 |
| ポップアップでEsc | 作成を取り消す |
| 作業バーの上端・下端をドラッグ | 開始・終了時刻を変更（15分刻み） |
| 作業バーの中央をドラッグ | 移動（週表示では別の日へも移動可） |
| 作業バーをダブルクリック | 編集ダイアログ（サブタスクの追加・削除、進捗率） |
| 作業バーを選んでDelete、または右クリック→削除 | 削除 |
| 左のタスクを空き時間へドラッグ | 1時間の作業バーを作成（後ろのバーまで1時間ない場合はその手前まで） |
| 左のタスクを作業バーの上へドラッグ | そのバーのサブタスクに追加 |
| Ctrl+Z | 直前の作業バーの操作を取り消す（20操作まで） |

### 進捗率と集計

- 進捗率は、タスク一覧の「進捗率」列のスライダー（5%刻み）、タスクの編集ダイアログ、作業バーの編集ダイアログで変更できる。変更した日の進捗履歴に記録し、100%にするとステータスを完了にするか確認する。
- 「集計・週報」タブの「集計」で、日／週／期間指定の集計を表示する。
  - 日別のタスク別時間（積み上げ棒。高さ＝稼働時間）
  - 週（期間）のタスク別時間（横棒。メイン時間の降順。サブ時間は括弧内に参考表示）
  - カテゴリ別の合計時間と割合（メイン時間。割合の合計は100%）
  - タスクごとの進捗（進捗率、実績時間／予定工数、サブ時間、完了予定日までの残り日数）

### 週報

「集計・週報」タブの「週報」で、対象週（月〜日）の週報をプレビューし、Excelに保存する。

- 左の「所感・課題」「来週の予定」（各400文字以内）は入力すると自動で保存される（`weekly_notes.json`）。
- 「来週の予定」が空のときは、未完了タスクを完了予定日の近い順に5件入れる。
- 「Excel保存」で `週報_<表示名>_<週開始日YYYYMMDD>.xlsx` を保存する。A4縦1ページ（タスク実績表が20行を超えると2ページ目に続く）。
- 「テキストをコピー」で、タスク実績・単発作業・来週の予定・所感・課題をプレーンテキストでクリップボードへコピーする。
- 対象週に記録がないときは「対象週の記録がありません」と表示し、出力しない。

### タスクのCSV取り込み

「タスク一覧」の「CSVから取り込む…」で、次の形式のCSVからタスクを一括で追加する。
文字コードは UTF-8（BOM付き）または Shift_JIS（自動判定）。タスク名以外は空でよい。
`categories.json` にないカテゴリは自動で追加する。不正な行はスキップし、取り込み後に行番号を表示する。

```
タスク名,カテゴリ,完了予定日,期限
次世代基板：抵抗変更等によるマイコンのバッテリ読み取り精度の検証・評価,次世代基板,,
IC微小電流測定用の治具作成（INA226＋Arduinoのプログラム）,治具,2026-11-20,
チャージャIC：10時間充電停止の確認,チャージャIC,,
```

### 他のメンバーの閲覧・チーム一覧

- 画面上部の「表示する人」でメンバーを選ぶと、その人のタイムライン・タスク一覧・集計・週報を読み取り専用で表示する（「閲覧モード：<表示名>」と表示）。
- 「チーム」タブで、選んだ1日について全員のタイムラインを1人1列で並べ、その下に各自の進行中タスクを表示する。
- 他のメンバーの記録は自動では更新しない。「更新」ボタンで読み込み直す。読み込めないメンバーは「読み込めませんでした」と表示する。

### 設定

「設定…」で、表示名、データフォルダ（次回起動から有効）、タイムラインの表示時間帯、カテゴリ（追加・名前の変更・削除）を変更できる。
カテゴリの名前の変更・削除は、そのカテゴリを使うタスクが自分のデータに0件のときだけできる。

### 保存・バックアップ・異常時の動作

| 状況 | 動作 |
|---|---|
| 起動時に共有フォルダへ接続できない | 「再試行」「別のフォルダを選ぶ」「終了」を選ぶ |
| 使用中に保存できない | 画面左下に赤で「未保存」。30秒ごとに再試行。終了時に未保存があれば警告 |
| JSONが壊れていて読めない | `<名前>.broken_<日時>` に改名し、最新のバックアップから復元するか確認 |
| 同じユーザーが別のPCで使用中 | 警告を出して閲覧モードで起動（もう一方が終了または2分以上応答がなければ通常どおり起動） |

- バックアップ: 起動時、その日最初の1回だけ `users/<ユーザー名>/backup/<YYYYMMDD>/` にJSON（自分のファイルと categories.json）をコピーする。直近14日分を残す。
- ログ: `%APPDATA%\WorklogCanvas\app.log`（起動・終了・エラー）。1MBで世代交代し、3世代を残す。予定の件名は記録しない。

## テスト

```bat
python -m pytest
```

データ処理（`worklog_canvas/core/`）は画面に依存せず、PySide6 なしでテストできる。
画面のテスト（`tests/test_ui_*.py`）は画面を表示せずに（offscreen で）動く。PySide6 が無い環境では自動でスキップする。

## データフォルダの構成

```
<データフォルダ>/
├─ categories.json          全員共通のカテゴリ
└─ users/
   └─ <Windowsのユーザー名>/
      ├─ profile.json        表示名
      ├─ tasks.json          タスク
      ├─ worklogs.json       作業バー
      ├─ weekly_notes.json   週次メモ
      ├─ .lock               起動中の印（二重起動の検出用）
      └─ backup/YYYYMMDD/    毎日のバックアップ（14日分）
```

JSONは UTF-8（BOMなし）・LF。各ファイルの項目名は SPEC.md 5.2 の項目名をそのまま使い、
`{"version": 1, "next_id": 4, "tasks": [...]}` のように形式の版と次の採番を持つ。

作業バーはメイン（タスクまたは単発作業）1つと、サブタスク（タスクまたは単発作業）を3つまで持てる。
作業バー同士は重ねられず、並行作業はサブタスクで記録する。

```json
{"id": "W-000001", "日付": "2026-11-10", "開始時刻": "10:00", "終了時刻": "11:30",
 "種別": "タスク", "タスクid": "T-0001", "タイトル": "",
 "サブタスク": [{"種別": "タスク", "タスクid": "T-0002", "タイトル": ""},
                {"種別": "単発作業", "タスクid": null, "タイトル": "打合せ"}],
 "メモ": "", "取込元": "手動"}
```

集計では、メインの時間（タスク別時間・稼働時間・カテゴリ別）と、サブタスクの時間（サブ時間）を分けて数える。
